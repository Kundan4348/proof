# Proof

A small phone web app against learned helplessness: one tiny task a day, a place to catch and reframe "I can't" thoughts, and a wall of evidence that effort works.

- Works offline after the first load and can be added to the home screen.
- All data stays in the browser on your device (localStorage). Use Export backup on the Week tab now and then.

Tests: `npm i playwright && node tests/e2e.mjs` (uses installed Chrome).
